# Jing Liu · Academic Homepage

Personal academic website of Jing Liu (刘静), a PhD student in mathematics at Shandong University, China.

**Website:** [liujingsweet.github.io/Jing-Liu-homepage](https://liujingsweet.github.io/Jing-Liu-homepage/)

The website presents research interests, education, publications and manuscripts, talks, and a downloadable PDF curriculum vitae.

## Project files

- `index.html` — page content and links.
- `styles.css` — typography, layout, and responsive styles.
- `app.js` — navigation highlighting and email copying.
- `assets/` — portrait, header illustration, favicon, and PDF CV.
- `sitemap.xml` — the public homepage URL for search engines.

## Local preview

Download the repository, keep the folder structure intact, and open `index.html` in a browser. No build step is required.

## Hosting

Hosted on GitHub Pages from the `main` branch and repository root. Repository write access remains restricted to the owner and explicitly authorized collaborators.
